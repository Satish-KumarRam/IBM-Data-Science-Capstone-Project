# IBM Data Science Capstone Project – SpaceX Falcon 9 Landing Prediction

## Project Overview
This project is the final capstone project for the IBM Data Science Professional Certificate.

The objective is to predict whether the Falcon 9 first stage will successfully land by analyzing SpaceX launch data using data science and machine learning techniques.

## Project Tasks
- Data Collection using SpaceX API and Web Scraping
- Data Wrangling
- Exploratory Data Analysis (EDA)
- SQL Analysis
- Interactive Visualizations with Plotly Dash
- Geospatial Analysis with Folium
- Machine Learning Model for Landing Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly Dash
- Folium
- Scikit-learn
- SQL
- Jupyter Notebook

## Project Files
- Data Collection Notebook
- Data Wrangling Notebook
- EDA Notebook
- SQL Notebook
- Interactive Dashboard (app.py)
- Machine Learning Notebook
- Dataset Files

## Results
The analysis identified that factors such as launch site, orbit type, payload mass, and flight number influence Falcon 9 landing success. The machine learning model achieved good prediction performance and the interactive dashboard provides useful visual exploration of the data.
